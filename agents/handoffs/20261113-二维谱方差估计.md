# 二维谱方差估计交接

- 会话实质工作日期：2026-11-13；交接创建于 2026-11-15。
- 任务：解释 Binospec 天空背景扣除后的二维谱仍有负值时，如何计算 SNR 与拟合使用的总方差，并核查管线误差文件的含义。

## 已核对与结论

- MMT 数据格式页将 `obj_counts_err_slits_lin.fits` 称为与天空扣除、重采样、合并的二维谱对应的“不确定度”，没有声明它仅为天空背景方差。来源：https://www.mmto.org/instrument-suite/binospec/binospec-information-for-users/binospec-reduced-data-formats/ 。因此仅凭该页不能认定需要另外加目标泊松项。
- 天空扣除后的单像素负值正常，不能直接作为泊松方差。若管线 `err` 为总标准差，使用 `err**2`；若独立证据确认只有背景等噪声，则用背景方差加非负目标信号模型的泊松方差。注意 ADU/e- 增益转换、天空噪声是否已包含，以及重采样引入的像素相关性。
- 本仓库 `data_prep/spec/read_and_cutout.py` 读取对应 `obj_counts_err_slits_lin.fits` 扩展并保存 `var_total=err**2`，同时校验 counts 和 err 的目标、形状及坐标头；`err<=1` 视为管线下限而屏蔽。
- `data_prep/spec/build_var.py` 的 `from_total_variance` 返回 `var_total-data`，只是为下游 `data+var` 接口准备的代数差值，可能为负，不能当作独立的高斯背景方差。
- 2026-11-13 检查时，工作区未提交的 `data_prep/spec/line_pipeline.py` 修改将上述代数差值缩放，再加平滑后的数据，可能导致负总方差或重复计数；`klm/kl_inference.py` 拟合时会再计算 `data_spec+var_spec`。本会话未修改代码，也未运行新测试；这些工作区修改之后可能已变化，续做前须重查。
- 现有 `diagnostics/slit112_variance/report.json` 与绘图脚本记录了 slit 112 的 `err**2` 和背景区残差比较，但它们不能单独证明误差中目标泊松项的组成。

# 成像邻近源手动遮罩方案

## 任务与进展

- 将 `data_prep/image/masking.py` 的硬编码椭圆位置替换为按 slit 保存的 JSON 方案。`data_prep/manual_image_mask.ipynb` 调用 `data_prep/image/manual_mask.py`，支持添加、删除、调整多个椭圆并预览、保存。
- 椭圆中心记录为相对目标星系的像素偏移；`main.py` 依据当前裁切图 WCS 定位目标再重放方案，改变 `--img_width`、`--img_height` 时仍可对齐。椭圆半轴为像素，角度为度。
- Notebook 的界面文字为英文，六个参数控件分三行、每行两个。右图用遮罩后仍有效的像素重新计算 2%/99.5% 显示范围，并更新 colorbar；左图保持原图范围。
- 光谱裁切方案位于 `data_prep/spec_crop_plans/`，成像方案位于 `data_prep/image_mask_plans/`。`main.py` 及两个手动流程默认读写各自目录，命令行 `--crop_plan`、`--image_mask_plan` 仍可指定其他路径。操作文档是 `data_prep/CROP_WORKFLOW.md` 与 `data_prep/IMAGE_MASK_WORKFLOW.md`。

## 关键决定

- 从未有成像遮罩且缺少方案的 slit 默认不额外遮罩；曾有硬编码遮罩的 slit 缺少方案时报错，避免旧遮罩静默消失。这些 slit 若不需遮罩，也要在 Notebook 保存空方案。
- 已有方案的 slit 若决定不遮罩，须删除所有椭圆并保存空方案；仅不点击保存仍会重放旧方案。
- 未自动迁移旧硬编码椭圆，因为旧坐标与图像尺寸的对应关系不可靠，需人工审核。

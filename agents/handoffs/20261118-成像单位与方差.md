### FITS 头与单位

| 字段 | 科学图 | 权重图 |
|---|---:|---:|
| `GAIN` | 6000 | 2.6 |
| `EXPTIME` | 1 s | 23539.46 s |
| `TOTEXPT` | 2400 s | 无 |
| `BUNIT` | 无 | `ADU`，注释指原始像素值 |
| `DnnnINUN` → `DnnnOUUN` | `counts` → `cps` | 同一组 drizzle 处理记录 |

- **科学图已经以每秒计数输出。** 100 条 drizzle 记录的输出单位都是 `cps`。同目录六个 Subaru 科学波段都满足 `GAIN = 2.5 × TOTEXPT`。这个规律强烈提示 `6000` 是按总曝光构造的有效增益。按这一解释，[读取代码](/D:/_RschArchives/RSCH3/kl_binospec/data_prep/image/read_and_cutout.py) 的 `science_raw * 6000` 得到的是**有效电子计数标度**。若目标是名义上的电子率，按这套约定可用 `science_raw * 2.5`，等价于当前 `image_data / 2400`。头信息支持这个推断，但没有逐像素的有效曝光标定。 [STScI 对 drizzle `cps` 的定义](https://www.stsci.edu/scientific-community/software/drizzlepac/frequently-asked-questions)
- **权重图可以用来保留相对权重，其绝对方差标度需要另行确定。** 两份头里的 100 个 `DnnnDEXP` 加起来约为 `23539.44 s`，几乎等于权重头的 `EXPTIME`，约为科学图 `TOTEXPT` 的十倍。这与逐 CCD 输入的曝光时间累计相符。权重头还记录了输入权重图和每个输入的 `DnnnWTSC`，整张输出权重图也确实有负值。如果原始 `W` 已经是科学图原始单位下的绝对逆方差，且科学图乘了 `k`，逆方差才应除以同一个 `k²`。目前用权重头的 `2.6²` 做转换缺少这个前提。 [IRAF Drizzle 权重参数说明](https://ftp.eso.org/scisoft/scisoft4/sources/iraf/extern/eis/doc/drizzle.hlp.html)
